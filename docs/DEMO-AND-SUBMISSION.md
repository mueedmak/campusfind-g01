# G01 demo and submission guide

Target a 10-minute screen recording. All three members must speak and explain their real contributions. Webcams are optional. Name the file `A3_G01_Video.mp4`.

## Recording outline

1. **0:00–1:00 Introduction:** group/topic, names and roll numbers, actual work split.
2. **1:00–5:00 Live demo:** home, board, search, status/category filters, sorting, item details, save/unsave. Submit an empty form for errors, then create a report and find/open it on the board. Submit a simulated ownership request. Visit `/items/99999` for the 404. Show mobile menu and layouts at 375/768/1280px. Explain that refresh resets state.
3. **5:00–9:00 Code walkthrough:** each member explains their area. Show app routes, awaited dynamic params, notFound(), metadata, layout, loading skeleton, typed reusable props, next/image, and different props on reused components. Explain Server vs Client Components. Trace a controlled input through validation into addItem() and the updated board.
4. **9:00–10:00 Wrap-up:** one actual challenge and solution, such as preserving state across client navigation through context. Show live Vercel deployment if available.

The loading skeleton can be brief locally. Use DevTools network throttling when navigating to an item detail.
